# Elysium testnet бот

Бот для активности в тестнете **[Elysium](https://elysium.kinetiq.xyz)** — L2 от Kinetiq для Hyperliquid — и в проектах его экосистемы.
Работает с любым числом кошельков, у каждого свой прокси. Управлять можно через **веб-панель в браузере** (`start.bat`) или из консоли.

> Всё происходит только в **тестнетах** (Elysium testnet, HyperEVM testnet, Hyperliquid testnet). Тестовые токены ничего не стоят.

## Быстрый старт

Если Python и Node.js уже стоят:

```bat
git clone https://github.com/ggRonin/elysium-kinetiq-bot.git
cd elysium-kinetiq-bot
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
start.bat
```

В открывшейся панели: вставь аккаунты и прокси → проверь настройки → **Сохранить** → **▶ Пуск**.

## Аккаунты, прокси и ключ CapSolver

### accounts.txt — кошельки

Один аккаунт в строке: **мнемоника (12 или 24 слова), запятая, прокси**.

```
word1 word2 word3 word4 word5 word6 word7 word8 word9 word10 word11 word12,user:pass@1.2.3.4:10000
```

- Прокси — HTTP в формате `логин:пароль@ip:порт`. Без прокси можно оставить пустым после запятой, но фосеты ограничивают выдачу и по IP.
- Строки, начинающиеся с `#`, пропускаются.
- Номер аккаунта в логе (`#1`, `#2`…) — это номер его строки в файле.

### Proxy.txt — запасные прокси

Один прокси в строке: `логин:пароль@ip:порт`.
Если прокси аккаунта перестаёт отвечать, бот берёт первый прокси из `Proxy.txt`, записывает его в `accounts.txt` вместо старого и удаляет из `Proxy.txt`.

### .env — ключ CapSolver

```
CAPSOLVER_API_KEY=CAP-xxxxxxxxxxxxxxxx
```

Нужен для фосета Elysium и крана Alchemy (решение капчи Cloudflare Turnstile). Ключ берётся в [dashboard.capsolver.com](https://dashboard.capsolver.com), на балансе должно быть немного денег (одна капча стоит доли цента).
Без ключа всё остальное работает, только фосет Elysium нужно выключить (`claim = 0`).

### Деньги на кошельках

Нужен тестовый HYPE в сети **Elysium testnet** — им платятся газ и суммы действий. Получить: фосет Elysium (0.1 в сутки), бридж с HyperEVM, кран Hyperliquid (см. ниже). Ориентир — от 0.3–0.5 HYPE на аккаунт, расход в день около 0.06–0.1 HYPE (плюс один раз 0.1 HYPE на домен `.ely`).

## Запуск

### Вариант 1. Веб-панель (рекомендуется)

Двойной клик по **`start.bat`**. Откроется окно консоли (это сама панель — не закрывай его) и браузер на `http://127.0.0.1:8765`.

В панели:

- **Аккаунты и прокси** — вставь списки, в заголовке пример формата и счётчик строк. Текст аккаунтов размыт, пока поле не в фокусе.
- **Карточки проектов** — у каждого проекта свои настройки, описание и ссылки на сайт и страницу поинтов. Поля с вариантами — выпадающие списки, у остальных подсказка под полем.
- **Сохранить** — записывает `config.ini`, `accounts.txt`, `Proxy.txt`, `.env`. Изменённые, но не сохранённые поля подсвечены жёлтым.
- **▶ Пуск** — сохраняет настройки и запускает бота целиком. **■ Стоп** — останавливает.
- **▶ Запустить отдельно** в карточке проекта — только этот проект, один проход по всем аккаунтам, потом бот сам останавливается
  (из консоли то же самое: `main.py --only kalos`, `--only bridge`, `--only faucet` и т.д.).
- **Терминал** справа — живой лог; предупреждения жёлтым, ошибки красным, ссылки на транзакции кликабельные.
- **Кнопки утилит** в карточках («Поинты сейчас», «Кран Hyperliquid», «Газ HyperEVM», «Кран Alchemy») запускаются параллельно с ботом.

Панель доступна только с этого компьютера (адрес `127.0.0.1`). Закрыл окно консоли — остановились и панель, и бот.

### Вариант 2. Консоль

```bat
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe main.py --limit 1     :: только первый аккаунт — для проверки
```

Остановить — `Ctrl+C`.

### Что происходит после запуска

1. На каждом аккаунте сразу проходят все включённые действия (фосеты, свопы, проекты).
2. Затем бридж HYPE: `bridge_rounds` кругов.
3. При `loop = 1` бот остаётся работать: раз в час забирает подтверждённые выводы, раз в сутки повторяет действия, раз в 6 часов печатает таблицу поинтов.

Две копии бота одновременно запустить нельзя (из консоли и из панели) — вторая напишет «Бот уже запущен в другом окне».
Полный лог всегда пишется в `logs/bot.log`.

## Газ на HyperEVM: зачем нужен и как получить

Вывод из Elysium в HyperEVM — это две транзакции: отправка в Elysium и **получение (клейм) в HyperEVM** примерно через час. За получение платится газ в HYPE **на HyperEVM**. Если там 0 — выводы так и висят в «Средствах к получению» на [странице бриджа](https://elysium.kinetiq.xyz/testnet-bridge).

Как дать газ всем аккаунтам:

1. **Получи HYPE на HyperEVM для одного кошелька-донора** (номер строки в `accounts.txt`, по умолчанию №1):
   - кран Hyperliquid — утилита `hl_faucet.py` (1000 USDC → ~8 HYPE в HyperEVM); работает, если у адреса есть аккаунт в мейннете [Hyperliquid](https://app.hyperliquid.xyz);
   - или кран [Alchemy](https://www.alchemy.com/faucets/hyperliquid-testnet) — 0.1 HYPE (то же условие про мейннет);
   - или переведи HYPE в HyperEVM testnet с любого своего кошелька.
2. **Запусти раздачу** — `hyperevm_gas.py` (в панели: карточка «Газ на HyperEVM», сначала «Проверить», потом «Запустить»).
   Донор докинет каждому до `topup` HYPE, а каждый аккаунт один раз выведет `big_withdraw` HYPE из Elysium — через час бот его получит, и у аккаунта будет свой запас газа.

## Настройки (config.ini)

Все параметры можно менять в панели. В файле у каждого есть комментарий. Значения `0 / 1 / 2` в ключах включения: `0` — выключено.

### [general] — общее

| Параметр | Что значит |
|---|---|
| `threads` | сколько аккаунтов работают одновременно |
| `loop` | `1` — работать постоянно (раз в сутки повтор), `0` — один проход и выход |
| `pause_min`, `pause_max` | случайная пауза между действиями, секунды |
| `terminal` | `all` — весь лог в терминале, `points` — только таблица поинтов (лог в `logs/bot.log`) |

### [faucet] — фосет Elysium

`claim = 1` — клеймить 0.1 HYPE в сутки (нужен ключ CapSolver).

### [bridge] — бридж HYPE

| Параметр | Что значит |
|---|---|
| `bridge` | `0` — выкл, `1` — только Elysium → HyperEVM, `2` — туда и обратно |
| `bridge_min`, `bridge_max` | сумма одного вывода, HYPE |
| `bridge_rounds` | кругов за запуск |
| `claim_min` | выводы меньше этой суммы не забирать (газ дороже суммы) |
| `hyperevm_reserve` | сколько HYPE на HyperEVM не тратить на депозиты обратно — газ на клеймы |

### Разделы проектов

| Раздел | Главное |
|---|---|
| `[wrap]` | режим `0/1/2`, сумма, повторы |
| `[swap]` | своп на Dex Da Costa: режим, сумма, проскальзывание |
| `[elyra]` | фосет, депозит HYPE (`supply_hype_*`, от ~0.015 HYPE чтобы шли поинты), доля USDC, займ `elyra_borrow` |
| `[token_bridge]` | токен `USDC`/`WHYPE`, сумма в единицах токена, `tbridge_buy = 1` — докупить токен, если не хватает |
| `[ely]` | регистрация домена `.ely`, максимальная цена |
| `[hunt]` | квесты Elysium Hunt, минт карты (нужна для квеста «транзакция») |
| `[kalos]` | чек-ин, сбор награды, своп KALOS, минт NFT, максимальная цена NFT |
| `[bunnypad]` | сделки (от 0.025 HYPE, иначе не засчитываются), запуск своего токена |
| `[perpme]` | покупка токена, сумма |
| `[games]` | ставки ELYSA.FUN (от 0.01) и Frog Flip (от 0.001, кратно 0.001) |
| `[hl_faucet]` | кран Hyperliquid в составе ежедневных действий |
| `[hyperevm_gas]` | донор, сколько докидывать газа, размер крупного вывода |
| `[hyperevm_faucet]` | кран Alchemy: порог баланса, потоки |
| `[points]` | таблица поинтов: включение, первая через N минут, дальше каждые N часов |

Изменения в `config.ini` применяются при следующем запуске бота.

## Поинты

Таблица по каждому аккаунту и проекту в формате **«мои / 10-е место лидерборда»**:

```
 #  кошелёк      Kalos (мои / 10-е)  BunnyPad (мои / 10-е)  Elyra (мои / 10-е)  ELYSA (мои / 10-е)  Hunt EXP (мои / 10-е)
 1  0xB99e…5b1F         120 / 17.5k              460 / 450         47.7 / 1387          100 / 8287             100 / 2300
```

- Печатается ботом через 20 минут после старта и потом раз в 6 часов; в любой момент — кнопкой «Поинты сейчас» или `python points.py`.
- **Kalos** пересчитывает поинты раз в сутки (около 00:00 UTC) — свежая активность появляется после пересчёта.
- **BunnyPad** считается из событий в сети ровно по правилам со страницы проекта.

Как начисляются поинты:

| Проект | Правила |
|---|---|
| Kalos | чек-ин (пул поинтов дня делится между отметившимися), минт NFT, торговля NFT, соцактивность, рефералы; по поинтам за сутки раздаётся 1 млн KALOS |
| BunnyPad | запуск токена +100 (до 10, первый +150), сделка от $1 +10, первая покупка и продажа по +25, +1 за каждые $10 объёма (HYPE = $40) |
| Elyra | 1 поинт за $1 позиции в час, HYPE ×2, займ ×2, позиция от $1 и не меньше часа |
| ELYSA.FUN | 666 поинтов за 1 HYPE ставки в монетку, +200 за 1 HYPE выигрыша, бонус за серию дней до 3500 |
| Elysium Hunt | EXP за квесты: чек-ин +100, транзакция +250 (нужна карта) |

## Частые сообщения в логе

| Сообщение | Что значит |
|---|---|
| `hl: кран недоступен — у адреса нет аккаунта в мейннете Hyperliquid` | кран Hyperliquid выдаёт только адресам, которые хоть раз пополняли настоящий Hyperliquid. Не ошибка |
| `бридж: N вывод(ов) готовы к клейму, но на HyperEVM нет HYPE на газ` | нужен газ на HyperEVM — см. [раздел про газ](#газ-на-hyperevm-зачем-нужен-и-как-получить) |
| `бридж: N вывод(ов) ждут подтверждения rollup (~45–60 мин)` | нормально, вывод получится примерно через час |
| `pending-actions недоступен (HTTP 502)` | сайт Elysium перегружен; бот повторит запрос сам |
| `rate limited` / `Rate Limit` | публичный RPC ограничивает частоту; бот ждёт и повторяет |
| `фосет уже клеймили, следующий через N ч` | кулдаун, бот попробует позже |
| `мало HYPE` | не хватает HYPE на сумму действия и газ — пополни кошелёк |
| `прокси не отвечает` | прокси аккаунта не работает; замени его в `accounts.txt` или добавь запасные в `Proxy.txt` |
| `Бот уже запущен в другом окне` | бот уже работает в другой консоли или в панели — сначала останови его |

## Безопасность

- `accounts.txt` (мнемоники), `Proxy.txt` (логины и пароли прокси), `.env` (ключ CapSolver) и `logs/` **не попадают в git** — они в `.gitignore`. Не удаляй эти строки из `.gitignore` и не выкладывай эти файлы.
- В репозитории только шаблоны: `accounts.example.txt`, `Proxy.example.txt`, `.env.example`.
- Используй для бота отдельные кошельки, а не кошельки с реальными деньгами.
- Веб-панель слушает только `127.0.0.1` — с других устройств её не открыть.
